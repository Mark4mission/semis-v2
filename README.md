# SeMIS v2 — 에어제타 보안종합정보시스템

기존 [kjsemis Google Sites](https://sites.google.com/view/kjsemis/)를 고도화한 Version 2.
정적 웹앱(HTML/CSS/JS)으로 어떤 웹서버(GitHub Pages 등)에서도 바로 호스팅 가능.

**접속 주소: https://mark4mission.github.io/semis-v2/** (GitHub Pages, `main` 브랜치 push 시 자동 반영)

## 구조

```
SeMIS_v2/
├── index.html       # 앱 셸 (로그인 모달, 헤더, 사이드바, 메인)
├── css/main.css     # 디자인 시스템 (반응형)
├── js/
│   ├── app.js       # 코어 엔진: 인증(SHA-256), 저장소+마이그레이션, 메뉴 엔진, 권한, 라우터
│   ├── modules.js   # 모듈: 대시보드(공지/보안등급), 시스템설정
│   ├── calendar.js  # 모듈: 일정관리 캘린더 (v2.1)
│   └── sync.js      # Supabase 공용 DB 실시간 동기화 (v2.1)
└── tests/
    └── run-tests.cjs # jsdom 테스트 스위트 (116건, CommonJS)
```

## 핵심 기능

- **로그인**: 모달에서 암호만 입력하는 간편 로그인. 암호는 SHA-256 해시로만 코드에 보관 (평문 미노출)
- **권한 3단계**: 시스템관리자(`mark3464`) / 보안관리자(`avsec`) / 일반사용자(`branch`)
- **메뉴 엔진**: 기존 사이트 전체 메뉴를 외부링크 메뉴로 이관 완료. 시스템 설정에서 웹주소 링크 메뉴 등록/수정/순서변경/권한설정 가능
- **사이드바 UX** (v2.22): `출입증`·`보안장비` 그룹 분리, 상단 툴바에 **모두 펼치기/접기** 토글 + **사이드바 축소/확대**(아이콘 전용 미니 모드, 라벨은 툴팁으로 표시), 그룹 펼치기/접기 및 축소 상태를 **접속 계정별**로 기억(같은 브라우저 공유 시에도 계정마다 독립)
- **대시보드**: 공지사항, 국가 항공보안등급 위젯(5단계, 시작~종료 기간 지정·만료 시 자동 복귀·적용일 예약·변경 이력), 보안점검 실적(계획 대비 완료율 + 이번 달 예정), CARES 환경센서(임계치 초과 강조 + 추이 그래프), 바로가기, 다가오는 일정. 카드 배치(v2.19): 좌 공지→환경센서→고장신고 / 우 등급→바로가기→일정→점검→만료→이수증
- **guest 경량 대시보드** (v2.19): 일반 사용자에게는 보안 카드 대신 🗞 보안 뉴스(Edge Function `semis-news`가 보안뉴스 boannews RSS + "항공/공항/화물" 제목검색을 수집, 항공·화물·사이버 3분류 + 카드 헤더 전체/항공/화물/사이버 필터 버튼, 30분 로컬 캐시) + 📊 항공보안 인사이트(보안등급 5단계·반입물품·검색절차·액체류 교육 시각화 탭, 우측 환경센서~만료 카드 사이) 중심의 화면 표시
- **보고체계 연락망** (v2.6): 기존 구글시트(8개 탭)를 랜딩페이지형 모듈로 내재화 — 30분 이내 SMS 보고 강조 배너, 구분별 보고 절차 아코디언, 사건별 보고처(①~④ 그룹), 기관별 연락처 카드(안전보안실·국토부·지방항공청 3청·비상안전기획관실·대테러/위기관리센터·TSA·서면보고 이메일), 전화/문자/메일 원터치 + 복사 버튼, 통합 검색(이름/기관/번호), 관리자 행 단위 편집(실시간 공유). **연락처 실데이터는 코드에 미포함** — 공용 DB(`semis_store` "contacts")에서만 동기화
- **지점 관리** (v2.7): 해외지점을 줌 가능한 세계지도(Leaflet) 위에 구역별 색상 마커로 표시 — hover 퀵 오버뷰, 클릭 상세 모달, 구역 필터·통합 검색, 목록 뷰. 입력: 구역(미주/유럽/중국/일본/아시아), 지점코드, IATA(주요 공항 좌표 자동 배치), 지점장/보안담당자/총원, 기내식, Layover 호텔, 주재 정비사 + 자유 추가 항목. CDN 차단 시 목록 자동 폴백
  - **교육 현황** (v2.8): 지점 상세 모달에서 지점별 교육 이력을 다건 기록 — 교육일·교관(강사)·교육내용·완료 인원·비고 + **첨부파일**(드래그앤드롭 또는 파일 선택, 지점당 교육 1건에 최대 20개·각 20MB). manager+ 등록·수정·삭제, 일반 사용자는 열람만. 첨부 목록은 **접이식(`<details>`, 기본 접힘·개수 표시)** + 펼침 시 최대 높이 스크롤로 모달 세로 길이 절약(v2.8.1)

- **CARES 연동** (v2.4, v2.6.1): 환경센서를 대시보드에 표시 — 기본은 임계치 초과 지표만(전체 정상 시 한 줄), "전체 표시" 토글로 8개 지표 확장. 무인증 공개 조회, 1분 자동 갱신. 연동 API 키는 코드에 두지 않고 공용 DB(`caresCfg`)에서 런타임 로드 (v2.6)

  - **색상 구분** (v2.36.5): 일자 확정 `[점검]` = **분홍**(`pink`, 진한 배경+흰 글씨) / 일자 미정 `[계획]` = **연분홍**(`rose`, 옅은 배경+진한 글씨+테두리). 구분(국내정기/해외공항 등)과 무관하게 점검 일정임이 한눈에 보이도록 통일했고, 일자를 확정하면 색도 자동으로 분홍이 됩니다. 매트릭스 뷰의 칩은 기존대로 구분별 색 유지
  - 신규 점검 등록 시 연동 체크박스는 **기본 켜짐**. v2.36.4 최초 부팅 시 취소를 제외한 기존 점검 전건을 1회 일괄 연동합니다(`DATA.inspSync` 플래그로 멱등)
- **개인정보 취급 원칙** (v2.36.2): 이름·사번·연락처가 포함된 명단은 **코드에 시드하지 않고 공용 DB(`semis_store`)에만** 보관합니다(저장소가 공개이므로). 해당 컬렉션 — `contacts`(보고체계 연락망) · `passOwners`(출입증 관리 책임자) · `supervisors`(보안감독자 현황) · `stationOfficers`(지점 보안담당자). `js/app.js`의 `seedSupervisors()`/`seedStationOfficers()`는 빈 배열만 반환하며, 회귀 테스트 O17이 실데이터 재유입을 막습니다
- **회의록 게시판** (v2.40, `js/minutes.js`, 라우트 `minutes`, 열람 mgr 이상): 회의 때마다 **빈 회의록을 즉시 열어 그 자리에서 기록**하는 범용 게시판. 보안장비 협의회는 전용 서식이 있는 별도 모듈로 유지
  - **폴더(그룹) 분류** — `DATA.minuteFolders`. 기본 6종 시드(항공보안파트 정례회의 · 유관기관 협의 · 지점·협력업체 회의 · 교육·훈련 강평 · 사고·이슈 대응 · 기타). 폴더마다 **기본 장소·기본 주재자**를 지정해 두면 새 회의록에 자동 반영. 폴더를 지워도 안에 있던 회의록은 **미분류**로 보존
  - **자동 채움** — [+ 새 회의록] → 폴더 선택만 하면 ① 폴더별 **회차 자동 채번**(제N차) ② **제목 자동 생성** ③ 회의일=오늘 ④ 장소·주재·시간은 **직전 회의에서 승계** ⑤ 작성자=로그인 계정 ⑥ **직전 회의 참석자 명단 승계**(서명은 반드시 초기화) ⑦ **직전 회의 미완료 결정사항 이월**(출처 표시). 승계 항목은 체크박스로 끌 수 있고, 만들기 전에 무엇이 채워지는지 미리보기로 보여줌
  - **검색** — 상단 검색창이 제목·본문·참석자·결정사항·태그·장소·주재자를 한 번에 훑음(공백 구분 다중 단어 AND). 폴더 사이드 · 연도 · 상태(초안/확정) 필터 병행. **전역 통합 검색**(Ctrl+K)에도 연동
  - **결정사항 추적 탭** — 전체 회의의 결정·조치사항을 한 화면에 모아 **미완료 우선 정렬 + 기한 초과 ⚠️ 강조**. 행을 누르면 해당 회의록으로 이동
  - **참석자 QR 서명** — 회의록별 6자리 코드(`SeMIS.signCodeFor`, id 기반 결정적 파생)에 더해 **QR 코드** 제공. 휴대폰 카메라로 스캔 → `#/sign/<코드>` → **암호 입력 없이 서명 화면 자동 진입**. 명단에 없는 참석자는 직접 입력 후 서명하면 자동 등록되고, 이름을 입력하면 지난 회의의 소속·직책이 자동으로 채워짐
  - **인쇄 2종** — ① A4 회의록(참석자 서명 이미지 포함) ② **QR 안내문**(대형 QR + 6자리 코드 + 접속 주소 + 사용 4단계) — 회의실 게시·배포용
  - **차기 회의 → 일정관리 자동 등록** — 차기 회의일 입력 + 연동 체크 시 `mn_<회의록id>` 일정 생성(1일 전 알림). 연동 해제·회의록 삭제 시 함께 정리
  - **권한** — 작성 mgr 이상 / 수정·서명코드 열람은 **본인 작성분 또는 hq 이상**. 상태는 `초안`(회의 중 계속 수정) ↔ `확정`
- **QR 코드 생성기** (v2.40, `js/qr.js`, `window.SemisQR`): 외부 라이브러리·CDN 없는 **순수 JS QR 인코더**(사내망·CDN 차단 환경 대비). QR Model 2 / 8-bit Byte(UTF-8) / 버전 1~10 / ECC L·M·Q·H / 마스크 0~7 자동 선택(ISO 벌점). `SemisQR.svg(text, {size, ecc, margin})` → SVG 문자열, `matrix()` / `dataUri()` 제공
  - 검증: 표준 구현(`qrcode` npm)과 **625개 조합 매트릭스 완전 일치**, 실제 디코더(`jsQR`)로 **112건 왕복 디코딩 성공**, 포맷정보 BCH 32조합 일치. 마스크 선택은 ZXing과 동일한 ISO 기준(N4)을 따르므로 일부 입력에서 `qrcode` npm과 마스크 번호가 달라질 수 있으나, 두 결과 모두 정상 판독됨
  - 적용처: 회의록 게시판 참석 서명 · **보안장비 협의회 참석 서명**(기존 6자리 코드 안내에 QR·주소 복사·QR 안내문 인쇄 추가) · **CAR 접수확인 원격 서명**(수검조직 안내 박스에 QR 삽입)
- **시스템 설정** (관리자 전용): 메뉴 관리 · 사용자/암호 관리 · 데이터 관리(백업/복원/초기화/수동 동기화)

## 데이터 저장 (v2.1 — 공용 DB 실시간 공유)

- **Supabase 공용 DB** (`semis-v2` 프로젝트, 서울 리전, 테이블 `semis_store`)에
  메뉴·공지·일정·보안등급이력·사용자설정이 실시간 동기화됨 → 다중 사용자 공유

- **실시간 반영**: 다른 사용자의 변경이 Supabase Realtime으로 즉시 반영 (CDN 차단 시 30초 폴링 폴백)
- 헤더의 동기화 배지(🟢 실시간 / 🟡 동기화 중 / 🔴 오프라인)로 상태 확인, 클릭 시 수동 동기화
- 백업 파일 복원 시 복원본이 공용 DB에 우선 반영됨(forcePush)
