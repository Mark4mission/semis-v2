SeMIS v2 는 어떤 시스템인가요?

소개
SeMIS(Security Management Information System)는 에어제타 항공보안 업무 전반 — 규정, 점검, 장비, 교육, 출입증, 회의, 일정 — 을 하나의 웹사이트에서 관리하는 통합 정보시스템입니다. 설치 없이 인터넷 브라우저만 있으면 PC · 태블릿 · 휴대폰 어디서나 사용할 수 있습니다.
⚡실시간 공유입력·수정하면 다른 사용자 화면에도 즉시 반영됩니다. 파일을 주고받을 필요가 없습니다.
🔐간편 로그인부여받은 접속 암호 하나만 입력하면 됩니다. 아이디를 외울 필요가 없습니다.
👥권한별 화면직무에 맞는 메뉴와 정보만 보입니다. 대외비는 권한자에게만 표시됩니다.
📱반응형 화면휴대폰에서도 화면이 자동으로 맞춰집니다. 현장에서 바로 기록하세요.
🔎통합 검색Ctrl+K 하나로 메뉴 · 문서 · 기록 · 링크를 한 번에 찾습니다.
🤖AI 비서 세미화면 오른쪽 아래 말풍선에게 물어보세요. 자료를 찾아주고 등록도 도와줍니다.

화면 구성과 기본 사용법

어디에 무엇이 있나요
화면은 세 부분으로 되어 있습니다
⬆️상단 헤더통합 검색창, 현재 보안등급 배지, 내 계정 이름, 로그아웃 버튼이 있습니다.
⬅️왼쪽 사이드바전체 메뉴입니다. 그룹을 접고 펼 수 있고, ☰ 버튼으로 사이드바 전체를 줄일 수 있습니다.
🖥가운데 본문선택한 메뉴의 내용이 표시됩니다. 처음 화면은 대시보드입니다.
꼭 알아두면 좋은 기본 조작
통합 검색 (Ctrl+K) — 상단 검색창에 단어를 입력하면 메뉴 · 공지 · 회의록 · 규정 · 일정 등 시스템 전체에서 한 번에 찾아줍니다.
행 클릭 = 상세 보기 — 목록에서 줄을 클릭하면 세부 내용이 열립니다. 파란 제목은 클릭하면 문서가 바로 열립니다.
🖨 인쇄 / PDF — 인쇄 버튼이 있는 화면(KPI · 회의록 등)은 A4 보고서 형태로 인쇄하거나 PDF로 저장할 수 있습니다.
📎 첨부파일 — 공지 · 회의록 · 청구 항목 등에 파일을 붙일 수 있습니다. 파일을 끌어다 놓기(드래그앤드롭)도 됩니다.
수정 권한 표시 — 등록 · 수정 버튼이 보이지 않으면 내 권한으로는 열람만 가능한 화면입니다.
휴대폰에서 쓸 때
화면이 자동으로 세로 배치로 바뀝니다. 왼쪽 위 ☰ 버튼으로 메뉴를 열고 닫습니다.
회의 서명, 일정 확인, 공지 열람, 세미와 대화는 휴대폰에서 특히 편리합니다.
화면이 이상하게 보이면 새로고침(F5) 을 한 번 해보세요. 업데이트 직후에는 브라우저가 이전 버전 화면을 기억하고 있을 수 있습니다.

로그인하면 처음 보이는 화면
대시보드는 "오늘 무엇을 챙겨야 하는가"를 한눈에 보여주는 화면입니다. 맨 위 요약 타일부터 보고, 필요한 카드로 내려가면 됩니다.
① 맨 위 — 요약 타일 (클릭하면 해당 메뉴로 이동)
타일의미
7일 내 일정일주일 안에 예정된 일정 수 — 클릭하면 일정관리로
이번 달 점검 완료이번 달 보안점검 완료/계획 건수 — 클릭하면 보안점검으로
CAR 기한 경과 · 진행 중부적합 시정조치 중 기한이 지난 건과 진행 중인 건
30일 내 만료 도래출입증 · 계약 · 이수증 · 장비 내용연수 중 만료가 다가온 건
② 카드 — 업무별 현황 요약
📢 공지사항 — 제목을 클릭하면 본문이 펼쳐집니다. "고정" 배지는 중요 공지입니다.
🌡 CARES 환경센서 — 장비실 온습도 등을 실시간 표시. 임계치 초과 시 붉게 강조됩니다.
🔧 보안장비 · 고장신고 — 장비 상태와 최근 고장 신고 현황입니다.
🚨 보안등급 — 현재 국가 항공보안등급과 변경 이력입니다.
📅 다가오는 일정 / 🕵️ 보안점검 실적 / 📈 KPI 진행현황 — 각 "전체보기"로 본 화면 이동.
📋 CAR — 기한 알람이 위험도 순으로 표시됩니다.
⏳ 만료 · 점검 도래 — D-일수와 함께 임박한 항목을 모아 보여줍니다.
⚡ 바로가기 — 자주 쓰는 화면 · 외부 시스템으로 한 번에 이동합니다.
일반사용자에게는 보안 카드 대신 보안 뉴스와 항공보안 인사이트(반입물품 · 검색절차 안내)가 표시됩니다. 같은 주소, 같은 화면이지만 권한에 따라 내용이 달라집니다.

일정관리 · 보안점검

서로 연동되는 두 화면
📅 일정관리 — 팀 공용 캘린더
일정 등록 — 날짜 칸을 클릭하면 등록 창이 열립니다. 기간 일정, 반복(매주 · 매월 등), 색상, 담당자, 리마인더(2주 전~1시간 전)를 지정할 수 있습니다.
드래그 이동 — 일정 막대를 마우스로 끌어 다른 날짜에 놓으면 이동합니다. Esc 로 취소.
보기 전환 — 일 / 주 / 2주 / 월 / 년 보기, ⤢ 전체화면 모드를 지원합니다.
구글 캘린더 연동 — 🔗 버튼의 구독 주소를 구글 캘린더에 추가하면 휴대폰 캘린더에서도 보입니다.
나에게만 보이기 — 개인 일정은 다른 사람에게 보이지 않게 등록할 수 있습니다.
🕵️ 보안점검 일정관리 — 연간 계획과 실적
연간 실적 요약 — 완료율 게이지와 구분별(국내정기 · 불시평가 · 해외공항) 진행 상황이 맨 위에 보입니다.
연간 매트릭스 — 구분 × 월 표에서 한 해 계획을 한눈에 봅니다. 빈 칸 클릭 = 새 점검 등록, 칩 클릭 = 수정, 칩을 끌면 계획 월 이동.
점검 결과 기록 — 시정조치 · 개선권고 · 현장시정 · 관찰사항 유형별로 결과를 남깁니다.
자동 연동: 점검을 등록하면 일정관리 캘린더에 분홍색 일정이 자동으로 생깁니다. 일자가 미정이면 연분홍 [계획], 확정되면 분홍 [점검] 으로 표시되고, 캘린더에서 일정을 옮기면 점검 일자도 함께 바뀝니다.
📋 부적합 · 시정조치 (CAR) — HQ 전용
점검에서 나온 부적합을 CAR → 시정조치(CAP) → 유효성 확인(FAT) 단계로 추적하고, 5×5 위험 매트릭스로 위험도를 평가합니다.
단계별 기한이 자동 계산되고, 기한이 다가오면 대시보드에 알람이 표시됩니다.

회의록 · QR 서명 · 협의회

회의 자리에서 바로 기록
🗒️ 회의록 게시판 — 모든 회의의 기록
1
새 회의록은 3초면 만들어집니다
[+ 새 회의록] → 폴더(회의체)만 고르면 회차 번호 · 제목 · 장소 · 참석자 명단 · 지난 회의 미결사항이 자동으로 채워집니다.
2
회의 중에는 논의 내용을 그대로 입력
서식(굵게 · 목록 · 표 · 이미지)이 되는 편집기입니다. 자동 저장이 켜져 있어 내용이 사라질 걱정이 없습니다.
3
참석자 서명은 QR 코드로
화면의 QR 을 참석자가 휴대폰으로 스캔 → 이름 확인 → 손가락으로 서명. 로그인이 필요 없습니다.
4
결정사항은 자동으로 추적됩니다
기한이 있는 결정사항은 일정관리에 자동 등록되고, "결정사항 추적" 탭에서 미완료 건을 모아 볼 수 있습니다. 다음 회의를 만들면 미결 건이 자동 이월됩니다.
5
끝나면 A4 인쇄
🖨 버튼으로 결재 · 보관용 회의록 문서를 바로 출력합니다.
🤝 보안장비 협의회 — 전용 서식 회의록
장비 고장 사례 표(발생일 · 장비 · 증상 · 근본원인 · 조치)가 있는 전용 양식입니다.
사례는 CARES(장비관리 시스템)의 고장 이력에서 자동으로 불러올 수 있고, 사례 행을 클릭하면 원본 기록이 열립니다.
참석자 서명 · 결정사항 · 첨부 · A4 인쇄는 회의록 게시판과 동일하게 동작합니다.
회의록 열람은 "참석 사실" 기준입니다 — 내가 참석한 회의는 언제든 볼 수 있고, 참석하지 않은 회의는 HQ 이상만 볼 수 있습니다.

🤖 세미(SeMI) — 화면 오른쪽 아래 말풍선
🔎자료 찾기"이번 달 점검 일정 알려줘", "프로에스콤 계약 담당자 누구야?" — 시스템 안의 자료를 찾아 답합니다.
✍️등록 도우미"다음 주 화요일 협의회 일정 등록해줘" — 초안을 보여주고, 확인하면 등록까지 해줍니다. (HQ 이상)
세미도 내 권한 범위 안의 자료만 찾고 보여줍니다. 팀 채팅 기능으로 다른 사용자와 대화할 수도 있습니다.
💡 자주 쓰는 팁
Ctrl+K 를 습관처럼 — 어느 메뉴에 있는지 몰라도 검색하면 나옵니다.
공지 · 회의록에 사진을 붙여넣기(Ctrl+V) 하면 자동으로 크기가 줄어 업로드됩니다.
표 · 목록 화면이 좁아 보이면 브라우저 창을 키우세요 — 화면 폭에 맞춰 열이 늘어납니다.
업데이트 후 화면이 예전 그대로면 새로고침(F5), 그래도 안 되면 Ctrl+Shift+R(강력 새로고침).
휴대폰 홈 화면에 바로가기를 추가해 두면 앱처럼 쓸 수 있습니다 (브라우저 메뉴 → "홈 화면에 추가").
